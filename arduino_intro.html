第三部分：编程基础

架构：Setup & Loop

Arduino 程序就像一个不断跳动的心脏，先初始化，然后永远循环。

"setup() 运行一次，loop() 运行一生。" 
void setup() {
  // 初始化串口，波特率设为 115200
  Serial.begin(115200); 
}

void loop() {
  // 读取 AD8232 输出的模拟信号
  int val = analogRead(A0); 
  // 实时上传至电脑分析
  Serial.println(val);      
  delay(4); // 采样频率约 250Hz
}

采样频率的重要性

为了还原心电波形细节，采样率必须达到信号带宽的2倍以上（Nyquist 定理）。
